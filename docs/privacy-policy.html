Privacy Policy

Last updated: June 2026

This privacy policy describes how the CalcaLight app (hereinafter "the app") handles user information. The app was developed by Raúl de Pablo with the purpose of turning an iPhone or iPad screen into a light table so that children can trace images onto paper.

1. Data stored by the app

The app stores only basic operational information on the device itself:

  • The number of donations made through the app, in order to personalise the thank-you message.
  • Usage preferences (for example, whether the app is being opened for the first time).
  • If you use the optional support chat (see section 7), an anonymous identifier and your draft messages are stored on the device.

The app does not store any images. Photos are accessed directly from the user's library to be displayed on screen and are discarded when the app is closed.

2. Access to the photo library

The app allows users to select an image from the device's photo library to use as a tracing template. This access is performed through the system photo picker (PhotosUI), which does not grant the app general access to the library: the user explicitly chooses which image to share on each occasion.

The selected image never leaves the device and is never sent to any server.

3. Where data is stored

The data described in section 1 is stored locally on the user's device using the standard system storage (UserDefaults). For the basic functioning of the app no proprietary servers or cloud services are used. Data sent through the optional support chat is processed by external infrastructure as described in section 7.

4. Use of data

Stored data is used solely for the functioning of the app: displaying the selected image as a light table, personalising the thank-you message after a donation, and delivering support chat messages between user and developer. Data is never used for analytical, advertising, or commercial purposes.

5. Sharing data with third parties

The app does not share any data with third parties for analytics, advertising, or tracking purposes. No such tools are integrated. The optional support chat relies on Cloudflare (cloud infrastructure provider) to host the backend and on Telegram (messaging platform) to deliver messages to the developer; these providers act as processors for the operation of that feature.

6. In-app purchases

The app offers optional donations to support development. These transactions are managed entirely by Apple through the App Store. The developer only receives confirmation that a purchase has been completed, without access to any payment data or associated personal information.

7. Support chat

The app includes an optional in-app support chat that lets users contact the developer with questions, suggestions, or issues. When you send a message:

  • An anonymous identifier (UUID) generated on the device is sent together with the message text and, if you choose to provide it, an alias or first name.
  • The data is transmitted over HTTPS to a backend operated by the developer on Cloudflare Workers (database hosted in Western Europe) and forwarded to a private Telegram bot for the developer to read and reply.
  • No account, email, or phone number is required. No tracking identifiers, IP-based profiling, advertising IDs, or analytics are collected.
  • Messages are retained for a maximum of 90 days from receipt and are then automatically deleted from the backend and (on a best-effort basis) from the Telegram bot. You may request earlier deletion at any time by writing to the contact address in section 11.

8. Deleting data

Local data: users can delete all data stored by the app on the device by uninstalling it. Upon reinstallation, the app will start fresh, including a new support chat identifier.

Support chat data: messages are auto-deleted after 90 days as described in section 7. Earlier deletion can be requested via the contact address.

9. Children

CalcaLight is designed to be used by children under adult supervision. The app does not collect personal information from any user. The optional support chat requires the user (typically an adult) to voluntarily type a message; it is not intended for unsupervised use by children. In-app purchases require Apple authentication (Face ID, Touch ID, or passcode), so they remain under the control of the adult responsible for the device.

10. Changes to this policy

This policy may be updated occasionally. The date of the last update appears at the top of this document. Continued use of the app after any change implies acceptance of the new version.

11. Contact

For any privacy-related enquiries, including data deletion requests, please write to: arenillas_argon.48@icloud.com

Die gespeicherten Daten werden ausschließlich für den Betrieb der App verwendet: das ausgewählte Bild als Leuchtkasten anzuzeigen, die Dankesnachricht nach einer Spende zu personalisieren und Support-Chat-Nachrichten zwischen Benutzer und Entwickler zu übermitteln. A app não armazena nenhuma imagem. As fotos são acedidas diretamente da biblioteca do utilizador para serem exibidas no ecrã e são descartadas quando a app é fechada.

2. Acesso à biblioteca de fotos

A app permite selecionar uma imagem da biblioteca de fotos do dispositivo para usar como modelo de decalque. Este acesso é feito através do seletor de fotos do sistema (PhotosUI), que não concede à app acesso geral à biblioteca: o utilizador escolhe explicitamente qual imagem partilhar em cada ocasião.

A imagem selecionada nunca sai do dispositivo e nunca é enviada para nenhum servidor.

3. Onde os dados são armazenados

Os dados descritos na secção 1 são armazenados localmente no dispositivo do utilizador usando o armazenamento padrão do sistema (UserDefaults). Para o funcionamento básico da app não são utilizados servidores próprios nem serviços na nuvem. Os dados enviados através do chat de suporte opcional são processados por infraestrutura externa, conforme descrito na secção 7.

4. Utilização dos dados

Os dados armazenados são utilizados exclusivamente para o funcionamento da app: exibir a imagem selecionada como mesa de luz, personalizar a mensagem de agradecimento após uma doação e entregar as mensagens do chat de suporte entre utilizador e programador. Os dados nunca são utilizados para fins analíticos, publicitários ou comerciais.

5. Partilha de dados com terceiros

A app não partilha nenhum dado com terceiros para fins analíticos, publicitários ou de rastreamento. Não estão integradas quaisquer ferramentas deste tipo. O chat de suporte opcional apoia-se em Cloudflare (fornecedor de infraestrutura cloud) para alojar o backend e em Telegram (plataforma de mensagens) para entregar as mensagens ao programador; estes fornecedores atuam como subcontratantes para o funcionamento dessa funcionalidade.

6. Compras na app

A app oferece doações opcionais para apoiar o desenvolvimento. Estas transações são geridas inteiramente pela Apple através da App Store. O desenvolvedor recebe apenas a confirmação de que uma compra foi concluída, sem acesso a dados de pagamento ou informações pessoais associadas.

7. Chat de suporte

A app inclui um chat de suporte opcional integrado que permite ao utilizador contactar o programador para dúvidas, sugestões ou problemas. Quando envia uma mensagem:

  • É enviado um identificador anónimo (UUID) gerado no dispositivo juntamente com o texto da mensagem e, se optar por fornecê-lo, um alias ou nome.
  • Os dados são transmitidos por HTTPS para um backend operado pelo programador em Cloudflare Workers (base de dados alojada na Europa Ocidental) e reencaminhados para um bot privado de Telegram para que o programador os leia e responda.
  • Não é necessária conta, e-mail nem telefone. Não são recolhidos identificadores de rastreamento, perfilamento por IP, IDs publicitários nem análises.
  • As mensagens são conservadas por um máximo de 90 dias desde a receção e depois eliminadas automaticamente do backend e (na medida do possível) do bot de Telegram. Pode solicitar a eliminação antecipada em qualquer momento escrevendo para o endereço de contacto da secção 11.

8. Eliminação de dados

Dados locais: o utilizador pode eliminar todos os dados armazenados pela app no dispositivo desinstalando-a. Após a reinstalação, a app começará do zero, incluindo um novo identificador do chat de suporte.

Dados do chat de suporte: as mensagens são eliminadas automaticamente após 90 dias conforme descrito na secção 7. A eliminação antecipada pode ser solicitada através do endereço de contacto.

隐私政策

最后更新：2026年6月

本隐私政策描述了 CalcaLight 应用程序（以下简称"本应用"）如何处理用户信息。本应用由 Raúl de Pablo 开发，旨在将 iPhone 或 iPad 屏幕变成描图灯箱，让儿童可以在纸上描绘图像。

一、应用存储的数据

本应用仅在设备本地存储基本运行信息：

  • 通过应用完成的捐赠次数，用于个性化感谢信息。
  • 使用偏好设置（例如，是否首次打开应用）。
  • 如果使用可选的支持聊天功能（参见第七节），将在设备上存储一个匿名标识符及您的消息草稿。

本应用不存储任何图像。照片直接从用户的相册中读取并显示在屏幕上，关闭应用后即被丢弃。

二、访问相册

本应用允许用户从设备相册中选择图像作为描图模板。此访问通过系统照片选择器（PhotosUI）进行，不会向应用授予对相册的一般访问权限：用户每次都明确选择要共享的图像。

所选图像永远不会离开设备，也不会发送到任何服务器。

三、数据存储位置

第一节所述的数据使用标准系统存储（UserDefaults）在用户设备本地存储。对于应用的基本功能，不使用任何专有服务器或云服务。通过可选的支持聊天功能发送的数据由外部基础设施处理，详见第七节。

四、数据使用

存储的数据仅用于应用运行：将所选图像显示为描图灯箱、在捐赠后个性化感谢信息，以及在用户与开发者之间传递支持聊天消息。数据绝不用于分析、广告或商业目的。

五、与第三方共享数据

本应用不与任何第三方共享数据用于分析、广告或追踪目的。未集成任何此类工具。可选的支持聊天功能依赖 Cloudflare（云基础设施提供商）托管后端，以及 Telegram（消息平台）将消息传递给开发者；这些提供商作为受托方处理该功能的运行。

六、应用内购买

本应用提供可选捐赠以支持开发。这些交易完全由 Apple 通过 App Store 管理。开发者仅收到购买完成的确认，无法访问任何支付数据或相关个人信息。

七、支持聊天

本应用包含一个可选的内置支持聊天功能，允许用户就问题、建议或反馈联系开发者。当您发送消息时：

  • 设备生成的匿名标识符（UUID）将连同消息文本一起发送，如果您选择提供，还会包含别名或姓名。
  • 数据通过 HTTPS 传输至开发者运营的 Cloudflare Workers 后端（数据库托管于西欧），并转发至私有 Telegram 机器人供开发者阅读和回复。
  • 无需账户、电子邮件或电话。不会收集追踪标识符、基于 IP 的画像、广告 ID 或任何分析数据。
  • 消息自收到之日起最多保留 90 天，之后将从后端自动删除（并尽力从 Telegram 机器人中删除）。您可以随时通过第十一节中的联系地址申请提前删除。

本地数据：用户可以通过从设备卸载应用来删除应用在设备上存储的所有数据。重新安装后，应用将重新开始，包括新的支持聊天标识符。

支持聊天数据：消息将按第七节所述在 90 天后自动删除。可通过联系地址申请提前删除。
